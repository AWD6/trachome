## Features
- **3D Interactive Tracheostomy Tube Explorer**: Jackson Silver (Uncuffed, Boiling 100°C 30 min), Shiley Cuffed, Fenestrated, and Koken Silicone T-Tube.
- **3-Stage Guided 3D Demonstration**: Slow animated demonstration + natural Thai female voice narration + slow replay + direct on-equipment dragging.
- **Hands-On 3D Practice Stages**: Sterile equipment tray selection, 4-direction outward wound wiping, inner cannula brushing & locking, and suctioning inside the neck tracheostomy opening.
- **Real Clinical Sputum & Stoma Photograph Triage**: Real clinical sputum photographs and stoma wound references with instant triage advice.
- **Caregiver Notebook & Admin Dashboard**: Anonymized `TH-XXXXXX` IDs, hashed PIN privacy, and password-protected Admin Dashboard.

## Deploy on GitHub Pages
This repository includes `.github/workflows/deploy-pages.yml` and pre-baked static Thai neural audio (`tts_cache/` + `tts_manifest.json`) so it runs out of the box on **GitHub Pages** with zero backend required.
